# Ping Point
Сайт комнаты настольного тенниса в Брянске. Выбранный вариант: 1-neon.

## Команды
- `python -m http.server 8766 --bind 127.0.0.1` — локальный просмотр.
- `node --check 1-neon/community.js` — проверка синтаксиса.

## Как здесь работает Autopilot
Требования, спецификация и таски — в `.autopilot/`, прогресс — `.autopilot/PROGRESS.md`.
Требование из manifest.md снимает только пользователь.
Правки без автопилота: сначала читать PROGRESS.md, после правки добавлять запись туда.
Коммиты называют только свои изменённые пути, требования указывают трейлером Requirements.
Не читать всю историю git: использовать git log -10 для нужного файла или git log --grep для требования.
