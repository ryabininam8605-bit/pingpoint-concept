# Приёмка по текущему брифу

Рабочие данные не используются. Чистый clone вне .autopilot, отдельная SQLite, ephemeral порт; cookie localhost изолирован от рабочего 127.0.0.1.

1. Зарегистрировать синтетический аккаунт по серверному HTTP с явными test согласиями, проверить в admin users без брони. Смена браузерной cookie не присваивает пользователя. Вход со второго cookie jar паролем получает только его брони; logout закрывает доступ. Попытка login1234 без пароля не работает.
2. Passkey программный authenticator с реальной подписью; другой origin/RPID/challenge/подпись и повтор запроса запрещены. Устройство/биометрический системный диалог вручную не эмулируется браузерным JS.
3. Даты/нули/табличные значения графиков соответствуют API; тестовые поступления не попадают live; дата игры не меняет дату поступления. Регистрация без брони/оплаты видима, выручку не увеличивает.
4. Mock HTTP ЮKassa подтверждает сумму серверной брони; поддельный webhook не подтверждает платёж, повтор не удваивает выручку/пропуск. Timeout/restart/late success/reordered events дают стабильное состояние. Возврат до подтверждения остаётся pending и не изображается завершённым.
5. Подтверждённый mock non-test paid создаёт настоящий QR; реальный SVG независимо декодируется. Неподключённый провайдер, test/demo, неоплаченный пользователь не получают работающего пропуска. Публичные ответы и журналы не содержат payload.
6. Reader endpoint с неверным bearer запрещён. До начала запрещено, начало разрешено, повтор во время разрешён, ровно конец запрещён. Отмена/возврат/перенос/неявка отзывают, старый код не оживает. Нет команд реальной двери.
7. UI админа и игрока на 375px и desktop: загрузка/пусто/ошибка, поиск/период/графики/таблица, регистрация/пароль/возможность passkey и оплата/сверка/QR состояния. Использовать только CUA для браузера; недоступность записать честно. Для экранов с законными согласиями/настоящими секретами не применять человеческие значения — только собственная изолированная QA-фикстура.
8. В конфигурации без полученных сведений явно «ЮKassa не подключена», «СКУД не подключена». Нельзя отметить полевую проверку или реальное списание выполненными без оборудования/магазина.
