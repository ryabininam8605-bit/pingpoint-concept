- [ ] Пользователи отдельны от контактов броней, registration-only visible, дата регистрации/последнего входа, поиск/пагинация/детали, брони/платежи, unverified contact явен.
- [ ] Dashboard period7/30/90/custom и live/test toggle; gross/refunds/net/registration/bookings/payment counts; поступления до комиссий подписаны; старые booking-date numbers не выдаются за выручку.
- [ ] Понятные SVG trends, axis/date/unit/точные значения и table fallback, нулевые дни, empty/loading/error/retry, не рисовать выдуманные демо-данные, mobile layout не распирается.
- [ ] Реестр оплат показывает provider/test/pending/refund/review и связь с бронью; не принимать local fake payment authority, деньги/admin права только сервер.
- [ ] Статусы подключений показывают отсутствующие параметры по именам и что ждём оборудование/магазин; события проходов с reason/date без QRсекретов. Никаких кнопок реального unlock.
- [ ] Существующие booking/settings/promos/manualquote и admin login/logout сохранены. Локальные community/consents панели подписаны как локальные. Учесть новый scriptorder03, не редактировать его файлы.
