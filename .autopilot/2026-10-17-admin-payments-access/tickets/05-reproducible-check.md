## Что должно заработать
G4 нашёл недостающий шаг установки dev-зависимостей. В чистом venv установка requirements.txt поднимает сайт, но общий check падает в независимом QR-decoder с ModuleNotFoundError cv2. README называет OpenCV/NumPy/Pillow уже имеющимися в текущем окружении и не даёт воспроизводимой команды.

## Из брифа, дословно
> «игроки которрые оплатили ... должны получть qr код»

## Критерии приёмки
- Создан requirements-dev.txt с runtime requirements и закреплёнными фактически проверенными dev-зависимостями OpenCV, NumPy, Pillow.
- README содержит копируемую установку полного набора проверки, отличает runtime от dev, не ссылается на уже имеющиеся пакеты этой машины.
- Чистый venv по одной команде устанавливает полный набор, node tests/check.mjs зелёный. Использовать venv независимой приёмки через согласование с checker, без параллельного pip или проверки в одном venv.
- Не менять продукт, тестовые assertions или превращать QR decode в skip.

Границы и швы — единая проверка и независимый decoder QR. interfaces.md и README фактической сборки.
