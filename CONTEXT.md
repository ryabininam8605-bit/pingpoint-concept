# Словарь проекта

- **Серверный аккаунт** — зарегистрированная учётная запись, которой сервер подтверждает права игрока. _Избегать_: локальный профиль, пользователь браузера.
- **Локальное сообщество** — сохранённые в браузере профили и данные сообщества, не дающие прав серверного аккаунта. _Избегать_: общий реестр, серверный аккаунт.
- **Гостевая бронь** — бронь, созданная без серверного аккаунта и принадлежащая текущей гостевой сессии. _Избегать_: бронь по телефону, ничья бронь.
- **Ключ устройства** — способ входа, при котором устройство подтверждает личность без передачи сайту биометрических данных. _Избегать_: отпечаток на сайте, биометрический пароль.
- **Попытка оплаты** — сохранённая операция, ожидающая подтверждения или сверки с платёжным провайдером. _Избегать_: полученные деньги, подтверждённая оплата.
- **Подтверждённая оплата** — оплата, состояние которой проверено у платёжного провайдера. _Избегать_: успешный редирект, уведомление об оплате.
- **Тестовая оплата** — операция в тестовом режиме, не считающаяся реальным поступлением и не дающая физический доступ. _Избегать_: реальная оплата, выручка.
- **Возврат** — отдельная операция возврата денег, подтверждаемая платёжным провайдером. _Избегать_: отмена брони как возврат, локальный возврат.
- **Пропуск** — выданный владельцу оплаченной брони непрозрачный QR для проверки доступа. _Избегать_: код брони, декоративный QR.
- **Онлайн-проверка доступа** — проверка пропуска сервером по текущему времени, оплате и состоянию брони. _Избегать_: офлайн-гарантия, команда двери.
- **Поступления** — сумма подтверждённых оплат до вычета возвратов и комиссии провайдера (gross). _Избегать_: чистые поступления, прибыль, стоимость броней.
- **Разница** — поступления за вычетом подтверждённых возвратов (net). _Избегать_: прибыль, выручка после комиссии.
